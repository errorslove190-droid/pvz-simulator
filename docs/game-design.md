# Геймдизайн: механики и экономика

Описано по коду версии из бэкапа 2026-09-04 (с исправлениями сохранений). Если меняешь цифры
в коде — обнови таблицы здесь. Где искать в коде — в скобках.

## Игровой день

1. **Приёмка** (`startAcceptance`, `onSort`, `finishAcceptance`). По таймеру приезжают коробки,
   их надо разложить в три корзины: **Свои** (номер есть в накладной), **Чужие** (нет в
   накладной), **Брак** (порванная коробка без этикетки). Горячие клавиши A/S/D или 1/2/3.
   Накладная = долги (обязательно) + заказы сегодняшних посетителей, сколько влезает на склад.
   Ошибочно принятые «чужие» и брак встают на склад **мёртвым грузом**.
2. **Посетители** (`startScene`). Каждый — персонаж с диалогом. Выбор: молча выдать /
   поговорить / отказать (дальше — стоять на своём или всё же выдать). Затем поиск коробки на
   полках склада (`showWarehouse`) и сканирование штрихкода удержанием (`scanStart`).
   Нет коробки — сцена «заказ не найден»: извиниться и пообещать к завтра (долг) или холодно
   отказать.
3. **Редкие гости**: скандалист (35 % дней со 2-го, 4 типа конфликта × 3 ответа,
   `SCANDAL_TYPES`), бомж Федор (7 % дней со 2-го, может утащить конфеты или пакеты,
   `BOMZH_EVENT`).
4. **Курьер возвратов** в дни 7, 14, 21… (`startCourierScene`): забирает мёртвый груз за деньги.
5. **Отчёт смены** (`showDayEnd`): доход, аренда и коммуналка, чистая прибыль, цель месяца.
6. **Магазин** (`renderShop`) → **новый день** через полноэкранную рекламу (`YG.startNewDay`).

## Стартовые условия

| Параметр | Значение |
|---|---|
| Деньги | 150 ₽ |
| Рейтинг | 3.50 (границы 1…5) |
| Склад | 3 места |
| Персонажи | 19 обычных + курьер + бомж; товары: 14 нейтральных, 10 мужских, 6 женских, 6 для пожилых |

## Приёмка

| Параметр | Значение | Где |
|---|---|---|
| Таймер | 30 с + 8 с за уровень «Налаженной сортировки» (до +16) + 10 с за кофе | `ROUND_DURATION`, `startAcceptance` |
| «Свои» из накладной | +15 ₽ каждая, всегда | `CORRECT_REWARD` |
| «Чужие» / брак верно | +15 / +25 ₽ из дневного пула `40 + 15 × размер накладной` | `rewardPool`, `BROKEN_BONUS` |
| Ошибка | −25 ₽ (с перчатками — без штрафа) | `WRONG_PENALTY` |
| Тележка | +5 ₽ за каждую свою посылку за уровень (до +15) | `finishAcceptance` |
| Поток коробок | 45 % свои, 35 % чужие, 20 % брак | `buildNextBox` |

## Посетители и рейтинг

Посетителей в день (`getDayLoad`): дни 1–3 — **3**, 4–11 — **4**, 12–21 — **5**, 22–42 — **6**,
43–63 — **7**, с 64-го — **8**; реклама на районе +2. Плюс должники, скандалист, бомж.

Доход с выдачи (`showResult`): `round((55 + 15 за пакеты, если клиент доволен) × (0.4 + рейтинг / 5 × 1.1))`
— при рейтинге 3.5 это 64 ₽, при 5.0 — 83 ₽ (с пакетами 105 ₽).

| Исход визита (`VISIT_RATING`) | Рейтинг |
|---|---|
| молча выдал | +0.02 |
| поговорил и выдал | +0.10 |
| сдержал обещание (долг) | +0.10 |
| поспорил, но выдал | −0.05 |
| извинился за пропажу (обещание) | −0.08 |
| холодно отказал в пропаже | −0.20 |
| выставил клиента | −0.25 |
| нарушил обещание | −0.50 |

Конфеты: положительные изменения рейтинга ×1.25.

**Долги**: обещание «найду к завтра» ставит заказ в накладную следующего дня обязательным.
Второе обещание по тому же заказу — −10 ₽ и −0.02; третье — клиент уходит (−0.15), долг сгорает
(`registerDebtPromise`). Невостребованная коробка через 2 утра становится излишком.

## Расходы по дням (`getDailyExpenses`)

| Завершённый день | Аренда + коммуналка |
|---|---|
| 1–3 | 0 ₽ (каникулы) |
| 4–7 | 70 ₽ |
| 8–14 | 150 ₽ |
| 15–21 | 260 ₽ |
| 22–28 | 350 ₽ |
| 29–42 | 480 ₽ |
| 43+ | 600 ₽ |

Курьер возвратов: 50 ₽ за штуку мёртвого груза (25 ₽ с камерами). Экстренный курьер в магазине:
50 ₽ + то же за штуку. Если денег < 60 ₽, склад полон и есть мёртвый груз — в конце дня район
вывозит его бесплатно (защита от тупика).

## Цели (`showDayEnd`)

9 000 ₽ к 28-му дню → 24 000 ₽ к 56-му → 40 000 ₽ к 84-му. Наград за цели нет, только текст.

## Реклама

- **Полноэкранная** — только при старте нового дня, не чаще раза в 60 с (`YG.interstitial`).
- **За вознаграждение** — расходники в магазине и мгновенный вывоз мёртвого груза со склада
  (`YG.rewarded`, `onDeadloadClick`).

# Журнал изменений

Новое — сверху. Пиши, что изменилось для игрока и почему; технические детали — в коммитах.

## 2026-09-27

- **Обзор игры** пятью агентами: ошибки, требования Яндекс Игр, экономика (симулятор на 100 дней),
  первый запуск и тексты, удержание. Сводка и план — `docs/review/00-summary.md`. Код игры обзор
  не менял; готовые исправления лежат в `docs/review/01-bugs-fixes.diff` и в отчётах.
- `docs/game-design.md`: исправлены неточности, найденные симулятором (должники входят в
  дневную нагрузку, цели считаются по остатку в день цели, округление бонуса конфет, выплата
  после смены рейтинга, сканер денег не даёт).
- **Проект в git.** Бэкап от 4 сентября импортирован без изменений (`backups/`), разобран на
  исходники `src/`; сборка `npm run build` воспроизводит исходный файл байт в байт.
- **Сохранения посреди приёмки.** Закрытие игры во время утренней приёмки приводило к тому,
  что после перезапуска приёмка пропускалась, склад был пуст и ни один заказ нельзя было выдать.
  Теперь игра возвращается к отчёту прошлого дня, и приёмка начинается заново.
- **Сохранения посреди визита.** Если закрыть игру во время визита клиента, которому обещали
  заказ, после перезапуска он пропадал, а вместо него приходил случайный посетитель. Исправлено.
- Таймер приёмки больше не идёт за открытой подсказкой после переключения вкладки.
- Реплика «Проходите, Федор, грейся» → «грейтесь»: сотрудник говорит на «вы».
- Добавлены `npm run smoke` (бот проходит дни и проверяет сохранения), локальный сервер с
  имитацией SDK, документация для ИИ-инструментов (`AGENTS.md`, `CLAUDE.md`, `docs/`).

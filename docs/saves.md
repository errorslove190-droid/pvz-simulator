# Сохранения

Код — `src/yg.js`, раздел «Сохранения».

## Где хранится

- `localStorage['pvz_sim_save_v1']` — всегда, сразу.
- Облако Яндекса: `player.setData({ save })` — не чаще раза в 30 с (лимит платформы
  100 запросов за 5 минут), при закрытии страницы (`pagehide`) — немедленно.
- При запуске (`loadSave`) берётся более свежая копия по полю `t`; облако ждём до 3,5 с.

## Фазы

Сейв помнит, откуда продолжать (`phase`), восстановление — в `YG.boot`:

| Фаза | Когда пишется | Как восстанавливается |
|---|---|---|
| `customers` | конец приёмки (`finishAcceptance`), после каждого визита (`continueCustomerFlow`) | `startScene()` — следующий посетитель по `visitorIndex` |
| `courier` | курьер вошёл (`startCourierScene`) | сцена курьера заново |
| `dayend` | отчёт смены (`showDayEnd`) | отчёт, расходы повторно не списываются (`lastExpenseDay`) |
| `shop` | магазин и каждая покупка | отчёт + магазин |

## Главное правило: сохранять только на границе шагов

Посреди приёмки или визита состояние изменено наполовину: коробки ещё не на складе, должник
уже вынут из очереди, заказ выдан, а `visitorIndex` не сдвинут. Сейв такого состояния ломал
игру после перезапуска (исправлено 2026-09-27):

- закрыл игру посреди приёмки → приёмка пропускалась, склад пустой, ни одного заказа не выдать;
- закрыл посреди визита должника → должник исчезал, вместо него приходил случайный посетитель.

Как устроено сейчас:

- `YG.save({ phase })` с фазой — вызывающий гарантирует согласованное состояние; снимок
  запоминается в `YG._checkpoint` (**глубокая копия** — `collectSave` отдаёт ссылки на живые
  массивы игры).
- `YG.save()` без фазы, отложенный облачный сейв и `pagehide`: если идёт приёмка или визит
  (`isMidStep`), пишется `YG._checkpoint`, а не текущее состояние. Потеря — максимум текущий
  шаг: после перезапуска игрок переигрывает этого посетителя или приёмку.
- Мёртвый груз, убранный за рекламу посреди визита, вычёркивается и из снимка
  (`YG.forgetParcel`), чтобы просмотр рекламы не пропал.

Регрессионные проверки — `npm run smoke`, сценарии 2 и 3.

## Что не сохраняется

`shelfCells` (раскладка по полкам — пересобирается), `activeVisitor`, `lastChoice`, спрайты
коробок (восстанавливаются по `spriteIdx`), состояние сцены и таймеров.

# Яндекс Игры: интеграция и требования

Номера пунктов — из комментариев в коде (требования к играм на платформе). Полный аудит
соответствия — в [review/](review/) после обзора. Код интеграции — `src/yg.js`.

## Как устроено

| Что | Где | Как |
|---|---|---|
| Подключение SDK (п. 1.1) | `src/index.html` | `<script async src="/sdk.js">`; без SDK игра работает локально |
| Инициализация | `initSDK` | ждём `YaGames` до 5 с, `YaGames.init()`, `getPlayer()` |
| Готовность (п. 1.19.2) | `loadingReady` в `YG.boot` | `LoadingAPI.ready()` после загрузки сейва, до старта игры |
| Разметка геймплея (п. 1.19.3) | `YG.gameplayStart/Stop` | старт — приёмка и посетители; стоп — отчёт, магазин, реклама, уход со вкладки |
| Пауза платформы (п. 1.19.4) | `initSDK` | `game_api_pause` / `game_api_resume` → та же пауза, что при уходе со вкладки |
| Потеря фокуса (п. 1.3) | `pauseGameForHide` | звук выключается, таймер приёмки и автотекст сцены стоят; также в альбомной ориентации телефона |
| Язык (п. 2.14) | `initSDK` | `environment.i18n.lang` читается, но игра только на русском |
| Сохранения (п. 1.9, 2.6) | раздел «Сохранения» | localStorage + `player.setData`, см. [saves.md](saves.md) |
| Полноэкранная реклама (п. 4.4, 4.7) | `YG.interstitial` | только при старте дня, не чаще раза в 60 с; звук и геймплей на паузе |
| Реклама за вознаграждение (п. 4.5) | `YG.rewarded` | только по кнопке игрока: расходники в магазине, вывоз мёртвого груза |
| Без прокрутки страницы (п. 1.10.2) | `styles.css` | `overflow: hidden`, `overscroll-behavior: none` |
| Без контекстного меню и лонгтапа (п. 1.6.1.8, 1.6.2.7) | `yg.js`, `styles.css` | `contextmenu` отменяется, `user-select: none` |

## Загрузка на платформу

1. `npm run build` → `dist/pvz-simulator.zip` (внутри один `index.html`).
2. Консоль разработчика Яндекс Игр → черновик игры → загрузить архив.
3. Перед отправкой на модерацию — `npm run smoke` и ручной прогон по чек-листу ниже.

## Ручной чек-лист перед модерацией

- [ ] Первый запуск на телефоне и на компьютере: загрузка, подсказка, приёмка, 3 посетителя, отчёт.
- [ ] Свернуть вкладку во время приёмки: звук пропал, таймер стоит; вернуться — продолжилось.
- [ ] Реклама при старте дня: звук на паузе, после рекламы игра продолжается.
- [ ] Закрыть игру посреди приёмки и посреди визита — после запуска всё корректно.
- [ ] Консоль без ошибок.
- [ ] Повернуть телефон горизонтально: подсказка «поверните телефон», игра на паузе.

## Известные замечания

- При запуске `startAcceptance` вызывает `audio.ensure()` до первого жеста игрока — браузер пишет
  предупреждение «AudioContext was not allowed to start». Это предупреждение, не ошибка, но
  модерация смотрит консоль — стоит создавать AudioContext только после жеста.

# Симулятор Сотрудника ПВЗ

Казуальная игра для [Яндекс Игр](https://yandex.ru/games/): утром раскладываешь коробки на
приёмке, днём выдаёшь заказы разным посетителям — от бабушек до скандалистов, вечером
считаешь прибыль и прокачиваешь пункт выдачи.

## Быстрый старт

Нужен только [Node.js](https://nodejs.org/) 18+.

```bash
npm run dev      # открыть http://localhost:8080 — игра с имитацией SDK Яндекс Игр
npm run build    # dist/pvz-simulator.zip — архив для загрузки в консоль Яндекс Игр
```

Для автотеста один раз `npm install && npx playwright install chromium` (Playwright и браузер), затем `npm run smoke`.

## Как устроен репозиторий

На платформу загружается один `index.html`, в который встроены все картинки и музыка (5 МБ).
Работать с таким файлом неудобно ни человеку, ни ИИ, поэтому здесь он разобран:

- `src/` — исходники: разметка, стили, `yg.js` (Яндекс SDK, сохранения, реклама), `game.js`
  (игра), `assets/` (картинки и музыка файлами);
- `tools/` — сборка, разбор бэкапов, локальный сервер, имитация SDK, автотест, карта кода;
- `backups/` — исходные версии игры как есть;
- `docs/` — [геймдизайн и экономика](docs/game-design.md), [сохранения](docs/saves.md),
  [требования Яндекс Игр](docs/yandex-games.md), [карта кода](docs/code-map.md),
  [журнал изменений](docs/changelog.md), [обзоры](docs/review/).

Сборка возвращает всё в один файл; для исходной версии результат совпадает с бэкапом байт в байт.

## Работа с Claude, Codex, Cursor и другими инструментами

Весь контекст — в репозитории, чтобы любой инструмент подхватил его с нуля:

- [`AGENTS.md`](AGENTS.md) — главный файл: что за проект, где что лежит, команды, правила
  (читают Codex, Cursor, Copilot и др.);
- [`CLAUDE.md`](CLAUDE.md) — для Claude Code, подключает `AGENTS.md`;
- решения и история — в `docs/` и в сообщениях коммитов.

Типичный цикл: попросить инструмент прочитать `AGENTS.md` → внести правку в `src/` →
`npm run smoke` → `npm run build` → коммит с понятным описанием → строка в
`docs/changelog.md`.
